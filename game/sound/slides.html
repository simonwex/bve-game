★ Side B · What is sound?

Sound is the air wiggling.

Something vibrates → it pushes the air → the air pushes your eardrum → you hear it. Fast wiggles sound high; slow wiggles sound low.

★ Side B · Fast or slow?

Fast wiggles = high. Slow wiggles = low.

★ Side B · Counting the wiggles

We measure wiggles in hertz (Hz).

1 Hz = one wiggle per second. 440 Hz = 440 wiggles every second — that's the "A" instruments tune to.

★ Side B · In your code

That number is the pitch.

tone(440, 400);  // 440 Hz, for 400 milliseconds

That's step 01 in the Sound Lab.

★ Side B · Do it again: loops

A loop repeats a sound.

for (let i = 0; i < 5; i++) {
  tone(880, 100);   // a short beep
  rest(150);        // a gap after it
}

★ Side B · Change the number each time

Move the pitch → a slide.

for (let f = 200; f < 900; f = f + 20) {
  tone(f, 30);
}

★ Side B · A tune is a list

An array = a list of pitches.

for (const hz of song) tone(hz, 220);
