JavaScript Cheat-Sheet

Zombie Maze · Week 2 · keep me handy

1 · A variable (a number we keep)

let makes a number the game remembers.

let health = 3;
game.score = 0;

2 · Change it (a little math)

Take the number, do math, put it back.

game.health = game.health - 1;  // lose 1
game.score  = game.score  + 10; // gain 10

3 · An if (a yes/no question)

Do something only when it's true.

if (game.health <= 0) {
  game.lose("Game over!");
}

Compare with: <= (at most) · >= · === (same) · && (and) · || (or)

4 · The hooks (= Scratch "when…")

start(game)once, at the beginning — when 🚩 clicked
use(player, game)when its button is pressed (makes a button)
onZombieHit(game)when you step on a zombie
everySecond(game)once per second

The card template — copy, rename, fill the blanks

registerCard({
  name: "My Mechanic",
  whatItDoes: "Say what it does.",
  limit: "Say what keeps it fair.",
  start(game)       { game.score = 0; }            // keep only the hooks you need
  everySecond(game) { game.score = game.score + 1; }
});

Add your card to the game — 4 steps

  1. Copy logic/_card-template.js and rename it, e.g. logic/score.js.
  2. Fill in the name and the blanks; delete the hooks you don't need.
  3. In index.html, add one line under "ADD YOUR CARD HERE": <script src="logic/score.js"></script>
  4. Save, then reload the page in Chrome. Your card is live!
